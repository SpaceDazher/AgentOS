# S1-014 prototype

Static offline mock UI. `index.html` + `app.js` + `style.css` load
`browser-contract.json` (generated by `build_fixtures.py` from `contract.py`;
contains both renderers' view models, assignments and schemas; **no oracle**).

- Keyboard-only operable, visible focus, graph nodes focusable, linear
  equivalent list for screen readers, disclosures are `<button aria-expanded>`.
- No `innerHTML` for data, no external script/font/telemetry, CSP `default-src 'none'`.
- Export = versioned envelope (`schemas/envelope.schema.json`) accepted by `importer.py`.
- `browser_probe.cjs` drives a real Chromium (Playwright) through consent →
  practice → 8 trials keyboard-only → export → re-import → forged binding
  rejection → withdrawal; outputs a synthetic technical envelope only.
  Env: `S1014_PLAYWRIGHT` (module path), `S1014_BROWSER` (executable).
