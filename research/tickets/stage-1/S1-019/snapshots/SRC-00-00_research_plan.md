# План исследования: развитие концепции «Личного агентного хаба» до уровня фич и моделей

**Цель (goal-d2a6e7fa):** провести исследование на 100–200 источников и довести концепцию
(личный агентный хаб для 15–20 человек) до уровня: каталог фич, архитектурные модели,
ментальная модель, онтологическая модель, математическая модель.

## Definition of Done

1. **10_source_registry.md** — единый реестр 100–200 уникальных источников: ID, название,
   автор/орг, год, тип, URL, ключевое утверждение, связь с артефактом, статус верификации.
2. **20_feature_catalog.md** — эпики → фичи → acceptance criteria; трассировка к H1–H16
   базового документа и к источникам.
3. **30_architecture_models.md** — контекстная/компонентная модели, модель данных,
   runtime-модель (состояния run/grant/task), топологии A/A+/B/C, контракты интерфейсов.
4. **40_mental_model.md** — роли пользователей, концептуальные объекты в голове человека,
   journey-карты, принципы видимости делегирования, анти-паттерны UX.
5. **50_ontology.md** — ядро онтологии (классы, отношения, жизненные циклы), SHACL-эскизы,
   выравнивание с PROV-O / A2A / MCP / SKOS.
6. **60_mathematical_model.md** — множества и графы, семантика authorize(), исчисление
   делегирования (алгебра грантов), ёмкость (Little/M/M/c), бюджеты (token bucket),
   доверие (Beta/EigenTrust), метрики риска.
7. **70_synthesis_and_gaps.md** — что изменилось в концепте после исследования, открытые
   вопросы, ограничения, adversarial-проверка полноты.

## Метод

- 6 доменных обследований субагентами (A протоколы, M prior art; B identity/delegation,
  C авторизация; D классические MAS, E LLM-агенты; F KR/provenance, L логика/верификация;
  G приватность/E2EE/local-first, H распределённые основы; I угрозы, J математика, K HCI).
- Дедупликация → мастер-реестр со статусами верификации (`v` / `c` / `u` / `x` /
  `x-исключён`).
- Синтез пяти артефактов с трассировкой «фича → источник → гипотеза».
- Adversarial-проверка по SELF-VERIFICATION.md перед завершением цели.

## Ограничения среды (раунд 1–2)

- web_search недоступен (нет DEEPSEEK_API_KEY), прямой HTTP(S) из песочницы заблокирован.
  Пользователь сообщил, что даст ключ → при появлении выполнить батч-верификацию URL.
- До тех пор все источники помечены Conf=u; 33 источника базового документа считаются
  ранее проверенными seed-источниками.

## Контролируемое отклонение от исходного DoD (раунд 13)

Фактический сбор дал 247 позиций (246 валидных после исключения I4), поэтому буквальное
ограничение «100–200 уникальных» не выполнено. Чтобы не удалять релевантные источники ради
метрики, принят двухуровневый результат: полный provenance-набор из 246 валидных работ и
курируемое ядро цитирования из 118 работ. Полные поля (автор/орг, год, тип, URL, claim,
artifact, статус) хранятся как составной реестр: индекс `10_source_registry.md` +
`sources/*.md`; `10_source_registry.md` не выдаётся за самостоятельную field-complete
таблицу. Это зафиксированное отклонение, а не ретроспективное изменение исходной цели.
